A Discord.js v14 ticket bot with a password-protected Express admin area for managing ticket panels, transcripts, users, DM logs, and site settings.

Created to make managing support tickets and custom button panels seamless, secure, and customizable.
<br/>

## 🛠️ • Features & Capabilities:

**Custom Ticket Panels** → Create and manage custom panel layouts via the web dashboard using Components V2.

**Express Admin Area** → Password-protected dashboard with session expiry, rate-limiting, and multi-user support.

**Transcripts & Logs** → Automatic HTML transcript generation on ticket closure, along with non-privileged direct-message logging.

**Dynamic Commands** → Each saved panel registers its own slash command dynamically across your guild.
